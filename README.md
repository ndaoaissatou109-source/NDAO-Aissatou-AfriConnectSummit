## 📖 Description du projet

AfriConnect Summit est un site web vitrine moderne développé dans le cadre d'un projet de développement web.

Il représente une conférence technologique panafricaine fictive réunissant des développeurs, des entrepreneurs, des designers, des investisseurs et des passionnés de technologies venus de plusieurs pays africains.

Le site est entièrement responsive et propose une expérience utilisateur fluide avec un design moderne, un mode sombre, des animations et plusieurs fonctionnalités développées en JavaScript Vanilla.
